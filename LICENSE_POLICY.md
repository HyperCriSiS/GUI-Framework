# License Policy

## Status

The project intends to use a strongly restrictive licensing model. The canonical license text has not yet been committed.

## Requirements before production distribution

- Select the final license explicitly before publishing distributable production code.
- Add the complete canonical license text as `LICENSE` in the repository root.
- Add SPDX identifiers to source files where appropriate.
- Document third-party dependencies and their license compatibility.
- Keep optional renderer dependencies isolated so they do not unintentionally alter the licensing obligations of unrelated modules.
- Define trademark/name usage separately from source-code licensing if required.

Until the canonical `LICENSE` file is added, no README or source header should claim a specific license.
